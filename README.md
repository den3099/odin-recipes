# odin-recipes
## Introduction
This is an implementation of "<a href="https://www.theodinproject.com/lessons/foundations-recipes">Project: Recipes</a>" from "<a href="https://www.theodinproject.com/">The Odin Project</a>" curriculum. The goal of the project is to create a basic website with a "main" page where the user could observe a list of recipes and navigate to the complete specifications of each one them through the links provided in the main page.

## Skills
* HTML
* Git
